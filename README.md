# Sillage-Noir

Pack complet du générateur de listes des Archives du Courant.

## Structure

- `index.html` : accueil
- `listes.html` : catalogue des listes
- `Generateur.html` : générateur
- `admin.html` : administration
- `data/armees/` : listes d’armée de référence
- `data/supplements/` : suppléments et restrictions
- `data/objets-magiques/` : objets magiques, chargés automatiquement lorsqu’ils sont renseignés
- `data/aptitudes/` : honneurs, esprits et kindreds
- `images/` : illustrations

Le générateur ne modifie pas les JSON. Les sauvegardes sont stockées localement dans le navigateur.
